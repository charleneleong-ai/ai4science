What is not established

  • No wet-lab measurement of anything — no KD, no expression, no sensorgram.
  • Tier 3 (affinity) is not addressed; peptide-dependence is not binding strength.
  • Only one co-fold predictor was used (see chai-consensus).
  • The aspartate rotamer any design must read has never been observed unliganded: 7OW4 has no coordinates for peptide positions 5 and 6.
  • No design was shown to exceed the control on any tier.
  • The tier-1 bar is now replicated but weak: the control's own wild-type difference is +0.0018 +- 0.0065 over 2 invocations, tied zero, so "below the bar" separates almost nothing. Two invocations bound the run effect; they do not make the bar sharp.
  • No selectivity mechanism is established. The per-variant ordering that would have been one did not survive pairing, and the grouping was post-hoc in the first place.

One predictor. The standing discipline on this project is that every load-bearing claim gets an independent second method, and that is not met here: the Chai-1 container was never located, so the consensus pass did not run. Every number on this page is Boltz 2.2.1 scoring structures Boltz 2.2.1 predicted. Replication bounds sampling and run-to-run error; it cannot detect a systematic error shared by every run, and the tier-1 inversion is exactly such a case.
